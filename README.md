# Physics Simulations in Python

This repository contains a collection of physics-based simulations developed in Python, focusing on classical mechanics and numerical methods.

## Overview

The project explores the motion of bodies using both analytical and numerical approaches.  
It is intended as an academic and educational project demonstrating applied physics, mathematical modelling, and scientific programming.

## Topics Covered

- Projectile motion without air resistance
- Projectile motion with air resistance (linear and quadratic drag)
- Comparison of analytical and numerical solutions
- Numerical integration methods:
  - Euler method
  - Verlet method
- Error analysis between analytical and numerical solutions
- Data visualization (trajectories, velocity, error plots)
- Basic animations of motion

## Technologies Used

- Python
- NumPy
- Matplotlib

## Project Structure (planned)

- projectile_no_drag.py — analytical solution
- euler_method.py — numerical integration using Euler method
- verlet_method.py — numerical integration using Verlet method
- air_resistance_linear.py
- air_resistance_quadratic.py
- plots/ — generated figures and visualizations
